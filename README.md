# 🎵 音标奇趣岛（IPA Phonics Quest）

专为儿童与英语初学者打造的**手机优先互动音标与自然拼读记词游戏**。围绕「**先会发音 → 记住字母组合规律 → 听音就能拼写单词**」的核心学习路径，覆盖全部 **48 个英语国际音标**。

## ✨ 核心功能

1. **🏝️ 音标图鉴岛（学发音 & 记规律）**
   - 涵盖 48 个国际音标，按儿童易懂的 5 大家族分组（短元音、长元音、双元音、清浊双胞胎辅音、鼻音与魔法辅音）。
   - 每个音标配备：**动态卡通口型图解**、**朗朗上口的顺口溜口诀**、**清浊声带震动提示**、**易混淆双胞胎一键对比**（如 `/æ/` vs `/e/`、`/p/` vs `/b/`）以及 **3 个高亮字母组合的示范单词点读**。
2. **🎧 听音捉精灵（练耳朵 & 辨清浊）**
   - 播放单词发音（支持标准/慢速听），智能混入易混淆双胞胎音标作为干扰项，锻炼听音辨音能力。
   - 连击加星激励，答错的音标会自动收入「待巩固错题本」供专项特训。
3. **🪄 音标拼词工坊（核心！用发音直觉记单词）**
   - 收录 45 个分级高频词（🌱入门三音词 → 🌿双字母组合 → 🌳双元音挑战）。
   - 展示图片、中文与逐个音标槽位，孩子听发音后按顺序点选字母组合方块（如 `sh` + `ee` + `p` = `sheep`），拼对后揭晓「记词秘籍」，真正建立“听音能写、见词能读”的直觉。
4. **🃏 音标记忆翻翻乐（趣味巩固）**
   - 手机竖屏 3×4 翻牌配对，把「音标卡」和「高亮字母单词卡」配对，每次翻牌自动发声。
5. **🏆 成长激励与家长设置**
   - 星星积分、48 音标掌握进度条、6 枚荣誉勋章、本地自动保存。
   - 支持切换**英式(UK)/美式(US)发音**、调节**慢速/儿童标准/原速**语速。

## 📱 如何使用（支持手机与电脑）

### 方式一：手机/平板畅玩（推荐，局域网同一 Wi-Fi）
1. 在项目目录打开终端，运行：
   ```bash
   node server.js
   ```
2. 终端会打印局域网地址（例如 `http://192.168.x.x:3000`）。
3. 确保手机与电脑连在同一个 Wi-Fi 下，用手机浏览器（Safari / Chrome / 系统浏览器）打开该地址即可畅玩！
4. **进阶技巧**：在手机浏览器点击「分享 / 菜单 → 添加到主屏幕」，即可像原生 App 一样全屏打开。

### 方式二：电脑直接打开
无需安装任何依赖，直接双击 [index.html](index.html) 即可在浏览器中游玩。
